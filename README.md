# حسابي (Hisabi)

تطبيق ويب لتقدير الأشغال وإصدار الفواتير للحرفيين المستقلين. يعمل بالكامل داخل المتصفح بدون خادم، وتُحفظ جميع البيانات في IndexedDB على جهاز المستخدم.

Construction estimator and invoice generator for independent craftsmen. No backend: all data stays in the browser (IndexedDB). Arabic, French and English, installable as a PWA and usable offline.

## المزايا / Features

- كتالوج خدمات بأسعار الوحدة (م²، م.ط، م³، وحدة، ساعة، يوم، كغ، جزافي)
- حاسبات هندسية: مساحة أرضية وسقف، جدران، دائرة، مثلث، محيط، مجموع أطوال، حجم
- مجاميع تلقائية لكل غرفة وكل طابق والمجموع الكلي، مع تخفيض
- عرض سعر وفاتورة قابلة للنسخ كنص وللطباعة أو الحفظ PDF
- واجهة بالعربية والفرنسية والإنجليزية (RTL تلقائي)
- نسخ احتياطي: تصدير واستيراد JSON

## الملفات / Files

| الملف | الدور |
|---|---|
| `index.html` | التطبيق كاملاً (HTML + CSS + JS) |
| `manifest.json` | بيانات التثبيت على الهاتف |
| `sw.js` | عامل الخدمة: العمل بدون إنترنت |
| `icon-192.png`, `icon-512.png` | أيقونات التطبيق |

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub وارفع الملفات كلها في جذره.
2. من **Settings ← Pages** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغط Save.
3. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/REPO/`.
4. افتح الرابط في كروم على الهاتف، ثم اختر **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.

التثبيت يتطلب HTTPS، وGitHub Pages يوفره.

## تحديث التطبيق

بعد أي تعديل على `index.html` غيّر رقم النسخة في `sw.js` (`hisabi-v2` إلى `hisabi-v3` مثلاً) ليحصل المستخدمون على التحديث.

## ملاحظة عن البيانات

كل هاتف يحتفظ ببياناته في متصفحه فقط، ولا تنتقل بين الأجهزة. ينصح المستخدم بتصدير نسخة احتياطية من **الإعدادات** بانتظام.
